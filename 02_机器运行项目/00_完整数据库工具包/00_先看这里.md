# 完整数据库工具包

这是功能最全的版本，包含通用取数程序、171 张表的字段字典、中文操作说明和性能测试结果。

## 文件夹用途

| 文件夹 | 用途 |
|---|---|
| `00_给人看的说明` | 人阅读：使用说明、性能报告、数据库表目录 |
| `01_机器运行文件` | 程序读取：Python 脚本、依赖清单、配置示例 |
| `02_双击运行入口` | 人操作：双击检查连接、下载示例数据 |
| `03_字段字典_人和机器都可看` | 查询数据库真实英文表名和字段含义 |
| `04_示例输出_给人查看` | Excel、CSV 等下载结果 |

复制整个文件夹到项目后，先双击 `02_双击运行入口/1_检查数据库连接.bat`。
