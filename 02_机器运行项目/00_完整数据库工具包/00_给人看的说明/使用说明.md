# 国金数据库抓取工具包

## 结论

将整个文件夹复制到任何项目目录后，进入 `02_双击运行入口`，双击 `1_检查数据库连接.bat`。如果看到“连接成功”，这个项目就可以直接下载数据库数据。

本工具默认读取当前电脑已安装的 Codex `gjdata` 配置，因此不用在每个项目重复保存账号密码。

## 最常用的两种使用方式

### 方式一：双击运行

1. 进入 `02_双击运行入口`。
2. 双击 `1_检查数据库连接.bat`，确认数据库可以连接。
3. 双击 `2_下载茅台日行情示例.bat`。
4. 成功后，在 `04_示例输出_给人查看` 中打开 Excel 文件。

### 方式二：让 Codex 帮你下载

把本文件夹复制到项目后，直接对 Codex 说：

- “用国金数据库工具下载 600519.SH 近三年的日行情，保存为 Excel。”
- “先查看 AShareFinancialIndicator 有哪些字段，再下载贵州茅台 2024 年报期财务指标。”
- “下载沪深 300 在 2025 年 6 月 30 日的成分权重。”

## 需要知道的表

| 需求 | 常用表 |
|---|---|
| A 股日行情 | `AShareEODPrices` |
| A 股估值 | `AShareEODDerivativeIndicator`、`AShareValuationIndicator` |
| A 股财务指标 | `AShareFinancialIndicator` |
| 基金净值 | `ChinaMutualFundNAV` |
| 基金股票持仓 | `ChinaMutualFundStockPortfolio` |
| 指数日行情 | `AIndexEODPrices` |
| 指数成分权重 | `AIndexHS300FreeWeight` |
| A 股交易日历 | `AShareCalendar` |

完整的表目录见 `00_给人看的说明/数据库表目录.xlsx`；每张表的字段中文说明见 `03_字段字典_人和机器都可看`。

## 命令行使用（可选）

在本文件夹空白处按住 Shift 并右键，选择“在终端中打开”，然后运行：

```powershell
# 测试连接
C:\ProgramData\miniforge3\python.exe "01_机器运行文件\国金数据库取数.py" 健康检查

# 查看字段
C:\ProgramData\miniforge3\python.exe "01_机器运行文件\国金数据库取数.py" 字段 --表 AShareEODPrices

# 下载单只股票的日行情
C:\ProgramData\miniforge3\python.exe "01_机器运行文件\国金数据库取数.py" 下载 --表 AShareEODPrices --代码 600519.SH --开始 20250101 --结束 20250131 --输出 "04_示例输出_给人查看\行情.xlsx"
```

## 回测数据注意事项

- 行情数据通常按 `TRADE_DT` 过滤；财务数据通常按 `REPORT_PERIOD` 过滤。
- `REPORT_PERIOD=20241231` 不代表该数据在 2024-12-31 当天就可用。回测必须依据公告日或实际披露日将财务数据滞后使用，否则会产生未来函数。
- 基金持仓来自定期报告，同样必须使用披露日，而不是持仓截止日作为可得时间。
- 下载后先检查是否有停牌、复权口径、缺失交易日和重复记录，再进入回测。

## 换电脑怎么办

如果复制到另一台电脑且没有安装本机 `gjdata`：

1. 进入 `01_机器运行文件`。
2. 将 `数据库配置示例.json` 复制并改名为 `数据库本地配置.json`。
3. 用记事本打开 `数据库本地配置.json`，填写数据库账号密码后保存。
4. 双击 `02_双击运行入口/1_检查数据库连接.bat`，看到“连接成功”即表示配置完成。

`数据库本地配置.json` 含密码，不要上传到 Git、微信或共享网盘。工具包中的 `.gitignore` 已默认忽略该文件。
