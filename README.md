# 期权研究共享包

这是一个面向研究复现和协作的中国ETF期权研究项目，快照日期为 **2026-09-07**。

项目包含两条研究线：

1. **510050 上证50ETF备兑 Call 策略库**：固定规则遍历、账本回测、融资/现金流建模、公司行动处理、风险审计和结果查询。
2. **588000 科创50ETF双卖 Delta 调节**：宽跨式双卖基础组合、Delta覆盖规则、方向状态、Theta过滤和EOD代理回测。

> 重要：本仓库是研究代码和研究记录，不是交易建议，也不是可直接连接券商执行的交易系统。现有结果尚未证明样本外优势；科创50的现有候选方案未通过测试期生产约束。

## 当前研究结论

### 510050备兑策略库

- 最新固定规则库包含 **576个模块**：Delta规则288个、OTM规则288个。
- BASE/STRESS和FULL_HISTORY/COMMON_PERIOD组合均已生成；576个模块全部运行完成，未静默丢弃失败模块。
- 已提供每日NAV、交易、换月、现金、融资、事件、市场状态、参数切片和独立复算结果。
- 最新验收批次的最大融资/NAV约36.82%；公司行动后有96个模块出现裸露敞口。
- 当前完成的是可复现回测工程和账本验收，不等于真实券商保证金仿真或实盘可执行。

### 588000科创50双卖 Delta调节

- 研究目标是每日14:40—14:50最多调仓一次，比较不调Delta、Delta归零、固定区间、方向偏置和Theta过滤等规则。
- 当前结果采用EOD代理，并非真实14:45盘口和实时Greeks。
- 三个候选执行方案均未通过测试期生产约束：测试期收益为负，部分方案调仓日比例超过40%。
- 推荐执行计划仅作为下一轮验证起点，不应直接上线。

## 环境要求

510050备兑策略主要依赖：

- Python 3.11或兼容版本
- pandas
- numpy
- pyarrow
- duckdb
- PyYAML

具体版本以验收批次下的 `requirements_reproduction.txt` 为准。数据库同步另外需要本机可用的 `gjdata`/MySQL连接环境；数据库账号、密码和本地配置不应提交到仓库。

588000脚本还依赖 `scipy`、`matplotlib` 和外部 `gj_db` 模块。脚本中的原始数据库路径来自历史运行环境，跨电脑运行前需迁移为本地配置或环境变量。

## 最小验证流程

进入机器项目目录后执行：

```bash
cd 02_机器运行项目
python -m pip install -r outputs/strategy_universe/20260828_113225_t1expiry/requirements_reproduction.txt
python -m unittest discover -s tests -v
python -c "from covered_call.query import StrategyUniverse; print(len(StrategyUniverse().registry))"
python scripts/verify_strategy_universe.py \
  --run outputs/strategy_universe/20260828_113225_t1expiry \
  --skip-replay
```

预期结果：测试通过、查询显示576个模块、核验结果为 `VALIDATION PASSED`。

注意：当前公开仓库默认不包含冻结行情和大型回测输出；因此没有这些本地数据时，不能直接完成历史结果重算。完整数据快照应通过受控方式单独共享，并依据其 manifest 和 SHA256进行核验。

## 数据和公开仓库边界

以下内容被 `.gitignore` 排除：

- `data_mart/` 冻结行情和数据库缓存
- `outputs/` 大型回测输出
- Parquet、压缩包和过程缓存
- 本地数据库配置、环境配置和密码文件

这样做是为了避免把大体积数据、个人环境信息或数据库凭据上传到公开仓库。数据库配置示例只包含占位符；运行数据库同步时，请使用本地未跟踪配置。

## 下一步研究

下一阶段优先级为：

1. 迁移科创50数据库依赖，确保跨电脑复现。
2. 为备兑策略加入授信上限、抵押折扣、追保和强平规则。
3. 完善除权、到期、长假、停牌、涨跌停和成交失败处理。
4. 拆分ETF收益、期权收益、成本和融资收益，进行滚动样本外验证。
5. 收集科创50真实14:40—14:50盘口、Greeks和逐腿持仓，完成盘中回放。
6. 基础模型通过后，再研究动态IV、趋势和波动率信号。

详细计划见 [`01_给人看的/03_期权下一步研究方案.md`](01_给人看的/03_期权下一步研究方案.md)。

## 研究限制

- 历史数据库发布版本不可得，无法完全排除供应商历史修订风险。
- 历史回测主要使用收盘或结算价加固定滑点，缺少完整Bid/Ask、盘口深度和排队成交模型。
- 部分历史Greeks缺失，缺失值不会被当作零风险。
- 当前融资模型不是券商真实保证金模型。
- 回测结果不能直接外推为未来收益。
