
## 4. 前端技术与页面结构

前端不依赖 Node.js 或浏览器端框架：

- 使用单页静态 HTML、CSS 和原生 JavaScript；模板位于 `templates/index.html` 与 `templates/strategy.html`。
- `update.py` 将数据内嵌到 HTML 的 JSON `<script>` 标签，同时生成 `output/latest.json`。
- 首页分为两层：
  - **每日 EOD 市场观测层**：510050、588000 的 ETF 收盘价、涨跌、成交量/成交额、20 日实现波动率、合约数、到期月数、Call/Put 成交量与持仓量、Greeks EOD 覆盖率和数据状态。
  - **冻结研究层**：510050 备兑策略的 BASE/STRESS 回测、研究参数、历史净值与冻结状态；588000 双卖的失败研究结论。
- 三条 510050 观察规则均可点击进入详情页，查看规则、回测、冻结末日状态、净值曲线、研究历程和限制。

网页明确将 `FRESH`、`PARTIAL`、`NO_DATA` 等数据质量状态与冻结研究状态区分开；EOD 指标不是实时盘口，也不等同于可执行交易信号。

## 5. 后端、数据与更新流程

### 5.1 Python 模块职责

| 文件 | 职责 |
| --- | --- |
| `build_baseline.py` | 从本地审核过的 Parquet / CSV 读取冻结研究结果，生成可公开的 `data/baseline.json`；不导出完整期权链、账户数据或凭据。 |
| `data_backend.py` | 每日通过服务器既有的 `gjdata` 安全配置读取日频 ETF、期权合约资料、期权日行情和 Wind EOD 估值。 |
| `update.py` | 合并每日市场数据与冻结研究基线，原子化生成 HTML、策略详情页和 `latest.json`。 |
| `deploy/build_package.py` | 创建不含凭据的 Windows 部署 ZIP，并输出 SHA-256 回执。 |
| `deploy/upload_and_install.py` | 经 PSRP 上传 ZIP、校验哈希、解压并运行 Windows 安装脚本。 |

### 5.2 数据表与关键字段

每日数据只使用日频、单表读取后再在 Python 中按合约代码汇总：

| 主题 | 表 | 关键字段 |
| --- | --- | --- |
| ETF 日行情 | `chinaclosedfundeodprice` | `TRADE_DT`、`S_DQ_CLOSE`、`S_DQ_PCTCHANGE`、`S_DQ_VOLUME`、`S_DQ_AMOUNT` |
| 期权合约资料 | `chinaoptiondescription` | 合约代码、品种代码、认购/认沽、执行价、到期日、合约单位 |
| 期权日行情 | `chinaoptioneodprices` | 收盘/结算价、成交量、成交额、持仓量、持仓变化 |
| Wind EOD 估值 | `windchinaoptionvaluation` | IV、Delta、Gamma、Theta、Vega、Rho、理论价 |

510050 只使用品种 `510050OP.SH`，588000 只使用 `588000OP.SH`，避免以合约代码前缀模糊匹配而混入其他期权品种。

### 5.3 每日调度流程

```text
Windows 计划任务（03:45）
  → deploy/windows/update.cmd
  → C:\JinkeDashboard\conda\python.exe update.py
  → data_backend.py 读取 gjdata 日频数据
  → update.py 原子写入 output/latest.json 与 HTML
  → Caddy 直接静态提供 /options/
```

任务最多运行 20 分钟；若数据源不可用，页面保留冻结研究内容并显示 `PARTIAL` 或 `NO_DATA`，不会把旧数据包装为新的交易结论。

## 7. 当前边界与后续方向

看板已经实现每日 EOD 数据更新，但以下内容尚不具备，不能包装为“实时交易”：

- 没有 Bid/Ask、盘口深度、订单参与率或成交回报；
- 没有经验证的真实券商保证金、授信、质押折扣、追保与强平路径；
- 588000 的双卖研究仍是 EOD 对 14:45 决策的代理回测，结论为“不建议上线”；
- 公司行动、合约调整、停牌、涨跌停及到期交割的实盘路径尚未完成全量重放验证。

因此，看板用于每日研究观测、数据质量检查和冻结策略复核，而不是自动交易系统。
